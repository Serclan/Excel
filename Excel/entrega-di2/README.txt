ENTREGA DI - INFORMES PDF

Contenido
- src/: código fuente de la aplicación Java Swing y del generador de informes.
- pom.xml: dependencias Maven; incluye PDFBox 3.0.1.
- src/main/resources/fonts/: fuentes DejaVu y su licencia.
- Informe_DEP01.pdf e Informe_DEP02.pdf: ejemplos personalizados para dos deportistas.
- Explicacion.pdf.txt: resumen del funcionamiento del informe.

Abrir y ejecutar
1. Descomprimir el paquete.
2. Abrir la carpeta del proyecto en NetBeans como proyecto Maven.
3. Usar un JDK 24 y permitir que Maven resuelva las dependencias.
4. Ejecutar la clase com.mycompany.excel.Excel.
5. En la aplicación, elegir deportista, fechas y la opción «Generar informe PDF».

Los PDF incluidos se generaron desde la aplicación. No se incluye target ni archivos temporales.
